# CloudRP loading screen

Готовый загрузочный экран для Garry's Mod. Страница не использует внешние шрифты или библиотеки и поддерживает штатные колбэки загрузки GMod.

## Файлы

- `index.html` — интерфейс, анимации и обработчики загрузки;
- `background.jpg` — фоновое изображение;
- `music.mp3` — фоновая музыка.

## Локальная проверка

Из этой папки запустить:

```powershell
python -m http.server 8765
```

Затем открыть `http://127.0.0.1:8765/?demo=1`.

## Публикация

Заменить одноимённые файлы в репозитории `mfrutis.github.io`, после чего GitHub Pages автоматически обновит страницу. Сервер должен использовать:

```cfg
sv_loadingurl "https://mfrutis.github.io/"
```

Изменения GitHub Pages иногда появляются через 1–3 минуты из-за кеширования.
